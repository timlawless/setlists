# AI-TO-AI DEVELOPMENT HANDOFF PACKET
## SYSTEM ROLE: Senior Full-Stack Architect / Pair Programmer

### 1. SYSTEM CONTEXT
- **Domain:** Mobile-first, non-commercial Progressive Web App (PWA) for multi-user band, song, and setlist management.
- **Architectural Paradigm:** Strict decoupling of business logic and presentation state.
  - `core/`: Vanilla TypeScript domain logic layer (change history engine, offline queues, metronome schedulers, data types). Framework-agnostic, strictly test-driven.
  - `prototype/`: React frontend presentation layer (Vite + TypeScript + Tailwind CSS + Lucide Icons).
- **Network/Data Architecture:** Distributed optimistic state synchronization powered by a Supabase Postgres relational database backend with Client-Side Realtime WebSockets (`supabase-js` broadcast channels).

### 2. CORE STATE SPECIFICATIONS

#### Database Schema Snapshot (PostgreSQL)
```sql
create table bands (id uuid primary key, name text, created_at timestamptz);
create table memberships (
  id uuid primary key, 
  user_id uuid references auth.users(id), 
  band_id uuid references bands(id), 
  role text check (role in ('admin', 'member')),
  unique(user_id, band_id)
);
create table changes (
  id uuid primary key, -- Generated on client for idempotency
  band_id uuid references bands(id),
  setlist_id uuid not null,
  sequence_number bigint generated by default as identity,
  author_id uuid references auth.users(id),
  action_type text check (action_type in ('add', 'remove', 'move', 'edit')),
  patch jsonb not null,
  inverse jsonb not null,
  created_at timestamptz
);
```

#### Core Active Codebase Blueprints
1. **Synchronization Layer (`src/hooks/useLiveSync.ts`):** 
   - Manages a custom React engine state sync hook wrapper.
   - Monitors network flags via DOM event bindings (`window.addEventListener('online')`).
   - Flushes an append-only `OfflineQueue` using oldest-first (`FIFO`) network transaction execution loops.
   - Handles network idempotency via unique SQL schema transaction traps (`Postgres error code 23505`).
   - Replays external edits into the local instance logic using a client broadcast socket channel configuration listener (`supabase.channel().on('broadcast')`).
2. **Presentation UI Matrix (`src/components/SetlistManager.tsx`):**
   - Renders interactive song layout grids using `@hello-pangea/dnd` for touchscreen mobile sort execution tracking.
   - Dispatches optimistic transformations directly to the presentation viewport before resolving backend database transactions.
