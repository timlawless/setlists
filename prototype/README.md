# UI prototype

Source for the interactive prototype (design canvas format). It is the UI reference for the real app:
bands, multiple setlists per band, song editing and reordering, original key and tempo with version picker,
editable YouTube link, change history with restore, offline demo, and a metronome with sound and flash.

All data in it is sample data. Keys and tempos are from public listings and vary by source.
Note: `Main.dc.html` loads a canvas runtime (`support.js`) that is not part of this repo.
